# الحالة الشاملة — مخطّط صحي احترافي

تطبيق ويب عربي (RTL) يعمل بالكامل داخل المتصفح، يحسب سعراتك وماكروزك ويبني خطة غذائية وتدريبية مخصّصة.

## المميزات

* حساب دقيق للسعرات والماكروز (سعرات · بروتين · كارب · دهون) بمعادلة Mifflin-St Jeor.
* إدخال بيانات InBody والتحاليل الطبية (سكري، كبد، كلى، دهون الدم، فيتامينات) مع قراءتها وتكييف الخطة عليها.
* خيارات وجبات حقيقية لكل دولة عربية (مصر، السعودية، اليمن، سوريا، السودان، ليبيا، الجزائر، تونس، المغرب) بلهجتها ومستوياتها المادية (اقتصادي/متوسط/مرتفع).
* أقسام للسلطات والفواكه وأنواع الخبز وحقائق غذائية دقيقة.
* شرح متحرّك أصلي للتمارين، وجدول تدريب مرن، ونصائح نوم ومتابعة.
* عدّاد زوّار، وطباعة/حفظ PDF.

## التشغيل

افتح ملف `index.html` في أي متصفح — لا يحتاج أي خادم أو تثبيت.
